# 推理证据

明确写出决策、目标、范围、允许使用的证据和硬约束。缺少决策输入时产生 `INPUT_GAP`，不得编造。

把每个基础项标为 `FACT`、`DEFINITION`、`CONSTRAINT`、`ASSUMPTION` 或 `UNKNOWN`，结论必须引用基础项 ID。移除后会改变结论的假设属于关键假设，必须同时给出证伪条件与成本最低的有效验证。

声称分类满足 MECE 时，必须定义全集、排除项、单一分类维度和每类无歧义的归属谓词，并测试普通、边界、未知和多属性样例。无法证明穷尽覆盖时报告 `MECE_UNVERIFIED`。

只有每个结论都可追溯、关键假设可证伪、未知项保持可见，且 MECE 声明已经证明或明确标为未验证时，决策才可以交给人类判断。
